# 🧾 Rupi — Gestión Inteligente de Obligaciones Financieras

**Rupi** es una aplicación web moderna que permite a las personas administrar sus créditos y préstamos personales con un nivel de detalle, simulación y transparencia que las entidades financieras tradicionales no ofrecen.

Construida con una arquitectura de microservicios, **Rupi** no solo es una herramienta útil para el día a día, sino también una demostración de habilidades en desarrollo de software profesional, pensada para un portafolio técnico de alto nivel.
